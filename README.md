# Workout Analystics Dashboard

A Streamlit-based dashboard for tracking workout performance over time.

## Features

- Exercise-specific filtering
- Max weight progression tracking
- Volume tracking and visualization
- PR date tracking
- Workout session metrics
- Workout entry form
- CSV-based data storage

## Technologies

- Python
- Pandas
- Streamlit
- Plotly

## Running Locally

Install dependencies:

pip install -r requirements.txt

Run the app:

streamlit run app.py
